# Legacy PL/I Batch System Documentation: KARTENBANK

## 1. System Overview & Production Status

This system processes credit card transactions, calculates interest/fees, and generates statements. The core production job is **KBJ00001**.

### Active Production Jobs
*   **KBJ00001 (KARTENBANK NACHT):** The primary nightly batch job.
    *   **STEP010 (KBP00001):** Books daily transactions.
    *   **STEP020 (KBP00002):** Calculates interest, fees, and updates account status.
    *   **STEP030 (KBP00003):** Generates statements and resets cycle counters.

### Dead / Decommissioned Jobs
*   **KBJ00002 (ALTER ZINSLAUF):** **DEAD.** Explicitly marked "SEIT 1997 NICHT MEHR EINGEPLANT" (Not scheduled since 1997). Replaced by KBP00002 in KBJ00001. Do not rebuild.
*   **KBJ00003 (MAHNBRIEFE):** **DEAD.** Explicitly marked "AUSGEPLANT 2016-01-31" (Unscheduled 2016-01-31). Letters are now generated by an external document system. Do not rebuild.

### Utility Routines (Shared)
*   **KBU00001:** Date utilities (Leap year, Days in month, Add days, Date compare).
*   **KBU00004:** Financial math (Rounding, Max).
*   **KBU00007/08:** Logging to SYSPRINT.
*   **KBU00011:** Error handling and termination.
*   **KBU00012/13:** Account file loading and search.
*   **KBU00015/16:** Transaction category balance aggregation.
*   **KBU00018/19:** Customer file loading and search.
*   **KBU00020:** Currency conversion (DM to EUR).
*   **KBU00021:** Validation helpers (Numeric, Signed, Date).
*   **KBU00022/23/24:** Record validation for Accounts, Transactions, and Card References.
*   **KBU00026/27/28:** Statistics accumulation and reporting.

## 3. Job KBJ00001: KARTENBANK NACHT

### STEP010: KBP00001 (UMSAETZE BUCHEN)

**Purpose:** Validate and book daily transactions.

**Inputs:**
*   `CTLCARD`: Run Date (YYYYMMDD) in positions 1-8.
*   `ACCTFILE`: Account Master (KTO_SATZ).
*   `XREFFILE`: Card References (XRF_SATZ).
*   `TCATFILE`: Previous Category Balances (TCA_SATZ).
*   `DALYTRAN`: Daily Transactions (TRN_SATZ).

**Outputs:**
*   `ACCTOUT`: Updated Account Master.
*   `TCATOUT`: Updated Category Balances.
*   `TRANOUT`: Booked Transactions (BUC_SATZ).
*   `REJECTS`: Rejected Transactions (ABW_SATZ).
*   `SYSPRINT`: Log.

**Processing Logic:**

1.  **Initialization:**
    *   Read Run Date from `CTLCARD`. If invalid, abort (RC 16).
    *   Load Accounts into memory (`KBU00012`).
    *   Load Category Balances into memory (`KBU00015`).
    *   Load Card References into memory (`XRF_LADEN`).
    *   Initialize Statistics (`KBU00026`).

2.  **Transaction Loop:**
    For each record in `DALYTRAN`:
    *   **Validation (`KBU00023`):** Check ID, Type, Category, Amount, MCC, Card, Date. If invalid, log warning and skip.
    *   **Duplicate Check:** Check if `TRN_ID` exists in session memory. If yes, set `@DOPP = 1`.
    *   **Debit/Credit Flag (`@SOLL`):**
        *   `@SOLL = 1` if `TRN_TYP` is '01' (Purchase) or '04' (Cash).
        *   `@SOLL = 0` otherwise.
    *   **Business Rules (`PRUEFEN`):**
        1.  If `@DOPP` is set, Reject (Code 110).
        2.  If `TRN_BTR` <= 0, Reject (Code 109).
        3.  If `TRN_TYP` is '05' (Fee) or '06' (Interest), Reject (Code 111). *Internal types only.*
        4.  If `TRN_TYP` is not '01', '02', '03', '04', Reject (Code 111).
        5.  If Card not found in `XRF`, Reject (Code 100).
        6.  If Card Status (`XRF_ST`) is not 'Y', Reject (Code 101).
        7.  If Account not found, Reject (Code 102).
        8.  If Account Status (`KTO_ST`) is 'C' or 'X', Reject (Code 103).
        9.  If `TRN_DT` > `KTO_ABDT` (Expiry), Reject (Code 105).
        10. If `@SOLL` is 1 AND `KTO_ST` is 'D' (Delinquent), Reject (Code 104).
        11. If `TRN_TYP` is '01' AND `TRN_MCC` is '7995', Reject (Code 108).
        12. If `TRN_TYP` is '04' AND `TRN_BTR` > `KTO_BLIM`, Reject (Code 107).
        13. If `@SOLL` is 1:
            *   Calculate `NewBalance = KTO_SLD + TRN_BTR`.
            *   If `NewBalance` > `KTO_KLIM`, Reject (Code 106).

    *   **If Rejected:**
        *   Write to `REJECTS` file (`ABW_SATZ`).
        *   Map Code to Text:
            *   100: 'KARTE UNBEKANNT'
            *   101: 'KARTE GESPERRT'
            *   102: 'KONTO UNBEKANNT'
            *   103: 'KONTO GESCHLOSSEN'
            *   104: 'KONTO IM VERZUG'
            *   105: 'KARTE ABGELAUFEN'
            *   106: 'KREDITLIMIT UEBERSCHRITTEN'
            *   107: 'BARGELDLIMIT UEBERSCHRITTEN'
            *   108: 'HAENDLERKATEGORIE GESPERRT'
            *   109: 'BETRAG UNGUELTIG'
            *   110: 'DOPPELTE TRANSAKTION'
            *   111: 'TRANSAKTIONSTYP UNBEKANNT'
        *   Update Statistics (Status 'A').

    *   **If Accepted:**
        *   **Update Account (`BUCHEN`):**
            *   If `@SOLL` is 1 (Debit):
                *   `KTO_SLD = KTO_SLD + TRN_BTR`
                *   `KTO_ZYK_SOL = KTO_ZYK_SOL + TRN_BTR`
            *   If `@SOLL` is 0 (Credit):
                *   `KTO_SLD = KTO_SLD - TRN_BTR`
                *   `KTO_ZYK_HAB = KTO_ZYK_HAB + TRN_BTR`
                *   If `TRN_TYP` is '02' (Payment): `KTO_ZYK_ZAHL = KTO_ZYK_ZAHL + TRN_BTR`
            *   **Points Calculation:**
                *   `IntegerAmount = TRUNC(TRN_BTR)`
                *   If `TRN_TYP` is '01' (Purchase):
                    *   Factor = 2 if `TRN_MCC` is '5411' (Grocery)
                    *   Factor = 3 if `TRN_MCC` is '5812' (Restaurant)
                    *   Factor = 1 otherwise
                    *   `KTO_PKT = KTO_PKT + (IntegerAmount * Factor)`
                    *   Cap `KTO_PKT` at 999,999,999.
                *   If `TRN_TYP` is '03' (Credit):
                    *   `KTO_PKT = KTO_PKT - IntegerAmount`
                    *   Floor `KTO_PKT` at 0.
            *   **Write Transaction History:**
                *   Create `BUC_SATZ` record.
                *   `BUC_TRN` = First 110 chars of `TRN_SATZ`.
                *   `BUC_KTO` = `KTO_NR`.
                *   `BUC_DT` = Run Date.
                *   Write to `TRANOUT`.
            *   Update Statistics (Status 'G').

        *   **Cash Fee (`GEBUEHR`):**
            *   If `TRN_TYP` is '04' (Cash):
                *   `RawFee = (TRN_BTR * 5.00) / 100`
                *   `Fee = MAX(RawFee, 10.00)`
                *   `KTO_SLD = KTO_SLD + Fee`
                *   `KTO_ZYK_SOL = KTO_ZYK_SOL + Fee`
                *   Create new Transaction Record:
                    *   `TRN_ID` = 'CF' + Substring(Original ID, 3)
                    *   `TRN_TYP` = '05'
                    *   `TRN_KAT` = '0001'
                    *   `TRN_QUELLE` = 'SYSTEM'
                    *   `TRN_TXT` = 'BARGELDGEBUEHR'
                    *   `TRN_BTR` = Fee
                    *   `TRN_HDL` = '000000000'
                    *   `TRN_MCC` = '0000'
                    *   `TRN_KARTE` = Original Card
                    *   `TRN_DT` = Run Date
                *   Write to `TRANOUT`.
                *   Update Statistics (Status 'E').

3.  **Finalization:**
    *   Write updated Accounts to `ACCTOUT`.
    *   Write aggregated Category Balances to `TCATOUT`.
    *   Print Summary Report (`KBU00028`).
    *   If any rejections occurred, set Return Code to 4.

### STEP020: KBP00002 (ZINSEN / GEBUEHREN / STATUS)

**Purpose:** Calculate interest, apply fees, update status.

**Inputs:**
*   `CTLCARD`: Run Date.
*   `ACCTFILE`: Updated Accounts from STEP010.
*   `TCATFILE`: Updated Category Balances from STEP010.
*   `DISCGRP`: Interest Rates.
*   `CUSTFILE`: Customer Master.

**Outputs:**
*   `ACCTOUT`: Updated Accounts.
*   `TRANOUT`: Interest/Fee Transactions.
*   `SYSPRINT`: Log.

**Processing Logic:**

1.  **Initialization:**
    *   Load Accounts, Category Balances, Customers, Interest Rates.

2.  **Account Loop:**
    For each Account:
    *   If `KTO_ST` is 'X' (Written-off), Skip.
    *   **Interest Calculation:**
        *   For each Category Balance (`TCA_SATZ`) for this Account:
            *   If `TCA_SLD` > 0 AND `TCA_TYP` is not '02' (Payment):
                *   Determine Rate:
                    *   If `KTO_GRP` is 'AKTION2010' AND Run Date is between '20100101' and '20111231', Rate = 0.
                    *   Else, Look up Rate in `DISCGRP` using `KTO_GRP` + `TCA_TYP` + `TCA_KAT`.
                    *   If not found, Look up Rate using 'DEFAULT' + `TCA_TYP` + `TCA_KAT`.
                *   If `KTO_ST` is 'D' (Delinquent), Rate = Rate + 3.00.
                *   If Customer FICO < 600, Rate = Rate + 2.00.
                *   `Interest = (TCA_SLD * Rate) / 1200`
        *   If Total Interest >= 1.00:
            *   `KTO_SLD = KTO_SLD + TotalInterest`
            *   `KTO_ZYK_SOL = KTO_ZYK_SOL + TotalInterest`
            *   Create Transaction:
                *   `TRN_ID` = 'ZI' + `KTO_NR` + '000'
                *   `TRN_TYP` = '06'
                *   `TRN_KAT` = '0001'
                *   `TRN_TXT` = 'SOLLZINSEN'
                *   `TRN_BTR` = TotalInterest
                *   `TRN_QUELLE` = 'ZINSLAUF'
                *   `TRN_HDL` = '000000000'
                *   `TRN_MCC` = '0000'
                *   `TRN_KARTE` = ''
                *   `TRN_DT` = Run Date
            *   Write to `TRANOUT`.

    *   **Dunning Fees:**
        *   If `KTO_ST` is 'A' or 'D':
            *   If `KTO_MINZ` > 0 AND `KTO_ZYK_ZAHL` < `KTO_MINZ`:
                *   `Fee = 35.00` if `KTO_MAHN` > 0, else `25.00`.
                *   `KTO_SLD = KTO_SLD + Fee`
                *   `KTO_ZYK_SOL = KTO_ZYK_SOL + Fee`
                *   `KTO_MAHN = KTO_MAHN + 1` (Cap at 99)
                *   Create Transaction:
                    *   `TRN_ID` = 'MG' + `KTO_NR` + '000'
                    *   `TRN_TYP` = '05'
                    *   `TRN_KAT` = '0002'
                    *   `TRN_TXT` = 'MAHNGEBUEHR'
                    *   `TRN_BTR` = Fee
                    *   `TRN_QUELLE` = 'ZINSLAUF'
                    *   `TRN_HDL` = '000000000'
                    *   `TRN_MCC` = '0000'
                    *   `TRN_KARTE` = ''
                    *   `TRN_DT` = Run Date
                *   Write to `TRANOUT`.
            *   Else:
                *   `KTO_MAHN = 0`

    *   **Overdraft Fee:**
        *   If `KTO_SLD` > `KTO_KLIM`:
            *   `Fee = 29.00`
            *   `KTO_SLD = KTO_SLD + Fee`
            *   `KTO_ZYK_SOL = KTO_ZYK_SOL + Fee`
            *   Create Transaction:
                *   `TRN_ID` = 'UL' + `KTO_NR` + '000'
                *   `TRN_TYP` = '05'
                *   `TRN_KAT` = '0003'
                *   `TRN_TXT` = 'UEBERZIEHUNGSGEBUEHR'
                *   `TRN_BTR` = Fee
                *   `TRN_QUELLE` = 'ZINSLAUF'
                *   `TRN_HDL` = '000000000'
                *   `TRN_MCC` = '0000'
                *   `TRN_KARTE` = ''
                *   `TRN_DT` = Run Date
            *   Write to `TRANOUT`.

    *   **Status Update:**
        *   If `KTO_ST` is 'A' AND `KTO_MAHN` >= 2, Set `KTO_ST` = 'D'.
        *   If `KTO_ST` is 'D' AND `KTO_MAHN` >= 6, Set `KTO_ST` = 'X'.
        *   If `KTO_ST` is 'D' AND `KTO_MAHN` = 0, Set `KTO_ST` = 'A'.

3.  **Finalization:**
    *   Write updated Accounts to `ACCTOUT`.
    *   Print Summary Report.

### STEP030: KBP00003 (KONTOAUSZUG, NEUER ZYKLUS)

**Purpose:** Generate statements, reset cycle counters.

**Inputs:**
*   `CTLCARD`: Run Date.
*   `ACCTFILE`: Updated Accounts from STEP020.
*   `CUSTFILE`: Customer Master.

**Outputs:**
*   `ACCTOUT`: Updated Accounts (Cycle fields reset).
*   `STMTFILE`: Statements (AZG_SATZ).
*   `SYSPRINT`: Log.

**Processing Logic:**

1.  **Initialization:**
    *   Read Run Date.
    *   Calculate Due Date = Run Date + 25 days.
    *   Load Accounts and Customers.

2.  **Account Loop:**
    For each Account:
    *   If `KTO_ST` is 'X', Skip.
    *   **Minimum Payment Calculation:**
        *   If `KTO_SLD` <= 0, `MinPay = 0`.
        *   Else if `KTO_SLD` < 25.00, `MinPay = KTO_SLD`.
        *   Else:
            *   `CalcMin = (KTO_SLD * 2.00) / 100`
            *   `MinPay = MAX(CalcMin, 25.00)`
            *   If `KTO_SLD` > `KTO_KLIM`, `MinPay = MinPay + (KTO_SLD - KTO_KLIM)`
            *   Cap `MinPay` at `KTO_SLD`.
        *   `KTO_MINZ = MinPay`

    *   **Statement Generation:**
        *   If `KTO_SLD` != 0 OR `KTO_ZYK_SOL` != 0 OR `KTO_ZYK_HAB` != 0:
            *   Resolve Customer Name. If not found, use 'UNBEKANNT'.
            *   If Euro Mode is ON, Convert `KTO_SLD` to EUR.
            *   Create `AZG_SATZ` record:
                *   `AZG_KTO` = `KTO_NR`
                *   `AZG_NAME` = Customer Name
                *   `AZG_SLD` = Balance (EUR if applicable)
                *   `AZG_MINZ` = `KTO_MINZ`
                *   `AZG_FAEL` = Due Date
                *   `AZG_PKT` = `KTO_PKT`
                *   `AZG_ST` = `KTO_ST`
                *   `AZG_SOL` = `KTO_ZYK_SOL`
                *   `AZG_HAB` = `KTO_ZYK_HAB`
            *   Write to `STMTFILE`.

    *   **Reset Cycle:**
        *   `KTO_ZYK_SOL = 0`
        *   `KTO_ZYK_HAB = 0`
        *   `KTO_ZYK_ZAHL = 0`

3.  **Finalization:**
    *   Write updated Accounts to `ACCTOUT`.
    *   Print Summary Report.
